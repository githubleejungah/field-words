# 필드워드 Field Words

**예문으로 익히는 FDE 실무 용어**

FDE(Forward Deployed Engineer: 고객 현장에서 문제를 정의하고 바로 만들어 해결하는 엔지니어) 강의 수강생이 현업 용어를 **실제 회의·면접·코드 리뷰 예문**으로 익히는 웹앱입니다. 프로젝트가 진행되는 순서대로 용어를 묶었고, 화면을 보지 않고 귀로만 들어도 공부할 수 있습니다.

- 앱 주소: [공개 후 채우기]
- 지금 버전: v0.1 · 용어 91개 · 헷갈리기 쉬운 짝 15개

> 이 앱은 로그인도 서버도 없습니다. 학습 기록은 각자 브라우저에만 저장되고 누구에게도 보내지 않습니다.
> 그래서 어떤 용어를 많이 틀리는지 자동으로 알 수 없습니다. 틀린 설명이나 필요한 용어는 앱의 **"의견 보내기"**로 알려 주세요.

## 무엇을 할 수 있나요

| 기능 | 설명 |
|---|---|
| **9단계 용어 카드** | 발견·기획 → 설계 → 개발 → 테스트 → 배포 → 운영 → 보안 → 개선 → 자동화. 뜻, 비유, 예문, 현업 함정, 면접 질문까지 한 카드에 |
| **검색** | 영어·한글·약어로 찾기. 목록은 알파벳순 |
| **발음 듣기** | 현업에서 실제로 읽는 발음. 약어는 글자로(P O C), 단어는 단어로 |
| **세 가지 모드** | 👀 보기 / 🚶 이동 중(카드 전체를 소리로 읽고 다음 카드로 자동 이동) / 🗣 말하기(30초 동안 직접 설명해 보기) |
| **오늘의 학습** | 확신도를 먼저 고르고 확인 문제 1개. "확실했는데 틀린 **착각**"을 따로 찾아 줍니다 |
| **간격 반복 복습** | 1·2·4·7·15·30·60일 간격으로 다시 묻고, 30일 넘게 기억한 용어는 🏅 장기 기억으로 셉니다 |
| **헷갈리는 짝 비교** | 폴링 vs 웹훅처럼 자주 헷갈리는 용어를 나란히 비교 |
| **면접 연습** | 용어별 면접 질문 → 30초 답해 보기 → 모범 답변 |

## 구조

```
[관리자 파이프라인]  (내 PC, Python)               [공개 사이트]  (GitHub Pages)
 용어 작성 → 검사 → 사람 승인  ──► glossary.json ──►  HTML · CSS · 자바스크립트
                                  (유일한 연결 고리)     학습 기록은 각 브라우저(localStorage)
```

- **서버가 없는 정적 사이트**입니다. 무료로 올릴 수 있고, 공격받을 서버가 없습니다.
- 사이트와 파이프라인은 `glossary.json` 하나로만 이어집니다. 파일 모양은 JSON Schema로 정하고 자동으로 검사합니다.
- 프레임워크와 외부 라이브러리를 쓰지 않습니다. 음성은 브라우저에 들어 있는 음성(Web Speech API)만 씁니다.
- 새 용어는 AI가 후보를 만들고, **사람이 승인한 것만** 공개합니다.

왜 이렇게 정했는지는 결정 기록(ADR: Architecture Decision Record)에 있습니다.

| [0002](docs/adr/0002-용어-그림과-혼동쌍-색.md) | 용어 그림(Mermaid·SVG)과 헷갈리는 짝의 색 |

## 폴더

```
site/            공개 사이트 (이 폴더만 배포)
  data/glossary.json   용어 데이터
  i18n/ko.json         화면 문구 (다른 언어는 파일만 추가)
  js/review.js         학습 기록·복습 규칙 (화면 없음)
  js/app.js            화면
pipeline/        관리자 도구 (검사, 종합 점검, 새 용어 승인)
schema/          glossary.json 규칙 (JSON Schema)
tests/           복습 규칙 단위 테스트
docs/            기능 목록, 데이터 모델, 작성 가이드, ADR
```

## 내 컴퓨터에서 실행하기

필요한 것: Python 3, Node.js(시험할 때만)

```bash
python -m http.server 8000 --directory site
```

브라우저에서 `http://localhost:8000` 을 엽니다.

**검사하기**

```bash
python -m venv .venv
.venv/Scripts/pip install -r pipeline/requirements.txt
.venv/Scripts/python pipeline/check_all.py
```

`check_all.py`는 데이터 형식, 복습 규칙 테스트, 비밀 값, 개인정보, 캐시 버전, 외부 스크립트를 한 번에 검사합니다.

**복습 규칙만 시험하기**

```bash
node --test tests/review.test.js
```

## 콘텐츠 출처 원칙

- 강의 자료는 **용어 목록만** 참고하고, 설명과 예문은 새로 씁니다.
- 유튜브·뉴스는 용어와 출처 링크만 남깁니다.
- 그림은 Mermaid와 직접 그린 SVG만 씁니다. AI 이미지나 다른 서비스 화면 캡처는 쓰지 않습니다.

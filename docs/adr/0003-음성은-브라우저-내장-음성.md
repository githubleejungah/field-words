# ADR-0003: 음성은 브라우저 내장 음성을 쓴다 (유료 음성 파일 만들지 않음)

- 상태(Status): **채택(Accepted)**
- 날짜: 2026-11-10
- 결정한 사람: 프로젝트 오너(사용자). 엣지에서 직접 들어 보고 "지금 것도 괜찮다, 유료로 더 하지 않아도 된다"고 결정.

## 1. 배경 (Context)
- 용어·뜻·예문을 소리로 들려주는 기능이 필요하다 (이동 중 모드, 발음 듣기).
- 처음에는 기기 기본 음성(윈도우 Heami)만 잡혀서 품질이 낮았다.
- 개선 후보: ① 기기에서 가장 좋은 음성 자동 선택 ② 음성 파일 미리 만들기(구글 클라우드 TTS, MeloTTS)

## 2. 결정 (Decision)
**브라우저 내장 음성(Web Speech API)을 그대로 쓰고, 기기에서 가장 좋은 음성을 자동으로 고른다.** 유료 음성 파일은 만들지 않는다.
- 음성 고르기 순서: Natural·Neural → Online·Google → Enhanced·Premium
- 기기별로 실제로 나오는 음성: 엣지 = 마이크로소프트 신경망 음성(선희, Ava 등), 안드로이드 크롬 = 구글 음성, 아이폰 = 애플 음성
- 영어 음성이 없는 기기는 한글 발음 표기를 한국어 음성으로 읽는다.
- 한 글자씩 읽는 약어는 글자를 띄워 넘긴다 (PoC → "P O C").

## 3. 결과 (Consequences)
### 좋아지는 점
- 비용 0원, 결제 수단 등록 없음, 음성 파일 관리 없음.
- 용어를 추가하면 바로 소리가 난다 (파일을 만들 필요 없음).

### 감수하는 점
- **기기마다 목소리와 품질이 다르다.**
- **화면이 꺼지면 읽기가 멈출 수 있다.** 이동 중 모드의 "화면 켜 두기(Wake Lock)"로 막는다. 배터리를 더 쓴다.
- 잠금 화면·이어폰 버튼 조작(Media Session)은 기기에 따라 잘 안 될 수 있다.

## 4. 다시 검토할 조건
- 실제 휴대폰 시험에서 화면 켜 두기로도 읽기가 자주 끊길 때
- 수강생이 "특정 기기에서 소리가 너무 나쁘다"는 의견을 여러 번 보낼 때
- 그때는 무료 범위의 음성 파일 방식(구글 TTS 무료 한도, MeloTTS)을 다시 비교한다.

# ADR-0002: 용어 그림은 Mermaid·SVG로, 혼동 쌍은 두 색 토큰으로

- 상태(Status): **채택(Accepted)**
- 날짜: 2026-11-10
- 결정한 사람: 프로젝트 오너(사용자). Claude가 조사하고 추천함. 색은 사용자가 정함.

## 1. 배경 (Context)

- 용어마다 "언제 쓰는지"를 그림으로 보여 주면 이해가 빨라진다.
- 조건: **비용 0원, 저작권 문제 없음.** 휴대폰에서도 빨라야 한다.
- 조사 결과: 용어마다 딱 맞는 무료 이미지는 없다. 상황 그림은 새로 그려야 한다.

## 2. 선택지 (Options)

| 방법 | 비용 | 저작권 | 속도 | 판단 |
|---|---|---|---|---|
| **Mermaid** (글자 → 그림, MIT) | 0원 | 문제없음 | 미리 SVG로 바꾸면 빠름 | ✅ 1순위 |
| **직접 SVG + Lucide(ISC)·Tabler(MIT) 아이콘** | 0원 | 고지문만 넣으면 됨 | 가장 가벼움 | ✅ 2순위 |
| Open Peeps (CC0) | 0원 | 조건 없음 | 가벼움 | ✅ 예문 상황 3종 그림에만 |
| unDraw | 0원 | 라이선스가 앱에 넣는 경우를 말림 | — | ❌ |
| Humaaans | 0원 | 출처마다 라이선스 설명이 다름 | — | ❌ 불확실 |
| AI 이미지 생성 | 유료 | 출처 불분명 | 무거움 | ❌ 글자 깨짐, 틀린 내용 |
| 실제 서비스 화면 캡처 | 0원 | 남의 화면·상표 | — | ❌ 단순하게 다시 그림 |

## 3. 결정 (Decision)

1. 그림 원본은 Mermaid(`.mmd`) 또는 SVG로 `pipeline/visuals/`에 둔다.
2. 관리자 파이프라인에서 **미리 SVG로 바꿔** `site/visuals/`에 둔다(빌드 시점 렌더링). 휴대폰은 Mermaid 프로그램(약 1MB)을 받지 않는다.
3. 그릴지 말지는 Claude가 판단한다. 기준: 순서·구조·비교·화면 중 하나로 상자 3~7개 안에 설명할 수 있을 때. **그림은 사람이 승인한 뒤 공개한다.**
4. 모든 그림에 `alt` 문장을 단다. 듣기 모드에서 TTS가 읽는다.
5. 혼동 쌍 색은 **디자인 토큰**으로만 관리한다.
   ```css
   :root {
     --pair-a: #f2e9e4;        /* 베이지: 혼동 쌍 A쪽 */
     --pair-a-border: #c9b3a6;
     --pair-b: #a7c4b5;        /* 세이지: 혼동 쌍 B쪽 */
     --pair-b-border: #7fa290;
   }
   ```
   그림 속 상자, 설명 배경, 퀴즈 버튼이 모두 같은 토큰을 쓴다. 다크 모드 값은 화면을 만들 때 정한다.
6. 색만으로 구분하지 않는다. 진한 테두리와 아이콘을 함께 쓴다(접근성).

## 4. 결과 (Consequences)

### 좋아지는 점
- 비용 0원. 그림이 글자 파일이라 Git에서 무엇이 바뀌었는지 보인다.
- 그림 한 장이 수 KB라 휴대폰에서도 빠르다.
- 같은 그림이 걷기 모드에서는 `alt` 소리 설명이 된다.

### 감수하는 점
- 관리자 컴퓨터에 **Node.js와 mermaid-cli**를 설치해야 한다.
- 사진처럼 화려한 그림은 만들 수 없다. 대신 정확하고 단순하다.
- MIT·ISC 아이콘을 쓰면 `THIRD_PARTY_LICENSES.md`와 앱의 "오픈소스 라이선스" 화면이 필요하다.

## 5. 다시 검토할 조건
- 라이선스 조건이 바뀌었을 때 (아이콘을 넣는 날 공식 LICENSE 파일을 다시 확인한다)
- 수강생이 "그림이 이해에 도움이 안 된다"고 할 때

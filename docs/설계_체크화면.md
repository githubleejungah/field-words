# 체크 화면 설계 (아는 것 · 모르는 것 · 헷갈리는 것)

- 작성일: 2026-11-10
- 상태: **A안 승인, 1차 구현 완료 (2026-11-10)** — 기록·상자 규칙(review.js + 시험 11개), 체크 흐름 ①~③, 목록 맨 위 오늘의 학습·진행 링·상태별 개수, 말하기 채점 연결, 간단한 마침 화면. 남은 것: 오늘의 마무리 전체 버전(#15), 대시보드의 착각 목록·성장 그래프, 퀴즈 사다리 3·4칸, 학습 중 새로고침하면 "다시 나올 카드" 순서가 사라지는 점
- 관련 Must: #8 복습(상자 7개), #9 확신도, #10 객관식 퀴즈, #11 5단계 상태, #13 하루 목표, #15 오늘의 마무리, #16 틀렸을 때 규칙

## 1. 한 줄 요약

목록 맨 위에 **"오늘의 학습"**을 두고, 누르면 같은 카드 화면에서 **"떠올리기 → 확신도 → 확인 문제 → 결과"** 순서로 한 장씩 체크한다. 결과가 쌓여 5단계 상태와 복습 날짜가 정해진다.

## 2. 지금 화면과의 관계

| 하는 일 | 어디서 | 기록 |
|---|---|---|
| 둘러보기·공부 | 목록 → 카드 (👀 보기) | 없음 |
| 걸으며 듣기 | 카드 (🚶 이동 중) | "들음"만 |
| 말로 설명 연습 | 카드 (🗣️ 말하기) | **맞음 / 일부 / 아직** (스스로 채점) |
| **체크 (새로 만듦)** | 목록 맨 위 "오늘의 학습" → 카드 | **확신도 + 정답 여부 → 5단계 상태, 복습 날짜** |

## 2-1. 새 용어는 먼저 배우기 (2026-11-10 사용자 승인)

| 카드 | 흐름 |
|---|---|
| **처음 보는 용어** | 📖 배우기 카드(카드 전체 + 전체 듣기) → [익혔어요] → **다른 카드 3장 뒤**에 확인 문제로 다시 나옴 ("방금 배운 용어 확인") |
| 처음 보는 용어 + 이미 앎 | 배우기 카드에서 [이미 알아요 → 바로 확인] → 그 자리에서 확인 문제 (틀리면 착각으로 잡힘) |
| **복습 용어** | 지금처럼 문제부터: 떠올리기 → 확인 문제 → 결과 (인출 연습) |

- 배우기 카드는 채점하지 않는다. 기록은 확인 문제에서 한 번만 남는다.
- 바로 묻지 않는 이유: 방금 본 것을 바로 물으면 잔상으로 맞힌다. 사이에 다른 카드를 두면 진짜로 떠올린다(간격 효과).

## 3. 목록 맨 위: 오늘의 학습

```
┌─────────────────────────────────────┐
│  (◔ 링)  오늘 8 / 20장                │  ← 진행 링: 오늘 목표 대비
│          12장 남음 · 약 6분            │  ← 남은 양을 시간으로
│          복습 5 · 새 용어 7            │
│                         [ 이어 하기 ] │
└─────────────────────────────────────┘
```
- 순서: **복습 예정 카드 먼저** → 남는 자리만큼 새 카드 (복습 빚 방지)
- 최소 목표(예: 3장)를 채우면 링에 ✓ 표시. 하루 목표는 **푼 카드 수**로 채운다(맞힌 수 아님).

## 4. 카드 한 장의 체크 흐름

```
① 떠올리기
   ADR [에이디알]  (발음 듣기)
   "뜻을 떠올려 보세요"
   [ 확실해요 ]  [ 헷갈려요 ]  [ 몰라요 ]        ← 확신도 (1번 누르기)

② 확인 문제  (확실·헷갈림을 골랐을 때만)
   ADR의 뜻은?
   ○ 중요한 구조 결정을 배경→선택지→결정→결과로 남긴 문서
   ○ 데이터의 칸과 값의 규칙을 정한 문서            ← 오답 보기: 혼동 쌍 → 같은 단계·등급
   ○ ...
                                                 (1번 누르기, 자동 채점)
③ 결과
   맞음:  "좋아요" + 뜻 한 줄 → 다음
   틀림:  내 답 | 정답 나란히 (혼동 쌍 색) + 차이 + 현업 함정
          착각(확실했는데 틀림)이면 "💡 의외죠?"
          "3장 뒤에 다시 나와요"
   몰라요: 카드 내용을 바로 펼쳐 공부 → "3장 뒤에 다시 나와요"
```

**문제 종류는 복습 상자에 따라 어려워진다 (퀴즈 사다리)**
| 상자 | 문제 |
|---|---|
| 1~2 | 용어 → 뜻 고르기 |
| 3~4 | 뜻 → 용어 고르기 |
| 5~6 | 예문 빈칸에 들어갈 용어 (Should) |
| 7~ | 면접 질문 30초 설명 → 맞음/일부/아직 (Should) |

## 5. 5단계 상태 (확신도 × 정답)

| | 맞음 | 틀림 |
|---|---|---|
| 확실해요 | ✅ 앎 | 🚨 착각 |
| 헷갈려요 | 🟡 불안한 앎 | 🟠 헷갈림 (무엇과 헷갈렸는지 기록) |
| 몰라요 | — | ⚪ 모름 |

**복습 상자 이동 규칙** (상자 7개: 1·2·4·7·15·30·60일 → 장기 기억 유지 120일)
- ✅ 앎: 한 칸 올림
- 🟡 불안한 앎: 그대로 (같은 간격으로 한 번 더)
- 🟠 헷갈림 · ⚪ 모름: 1번 상자 (상자 4 이상이었으면 두 칸만 내림)
- 🚨 착각: 1번 상자 + **오늘의 마무리 맨 앞**

## 6. ⚠️ 결정이 필요한 것: "카드당 한 번 누르기" 원칙

이 설계는 **확신도 1번 + 확인 문제 1번 = 2번 누르기**입니다. 착각(확실한데 틀림)을 잡으려면 "확신"과 "정답"을 둘 다 알아야 하기 때문입니다.

| 안 | 누르기 | 착각 잡기 | 비고 |
|---|---|---|---|
| **A. 확신도 → 확인 문제** ⭐ 추천 | 몰라요 1번 / 나머지 2번 | ✅ 정확 | 학습 효과가 가장 큼(떠올린 뒤 확인) |
| B. 확인 문제만 + "모르겠어요" 보기 | 1번 | ❌ 착각을 구별 못 함 | 가장 빠름 |
| C. 확신도만 | 1번 | ❌ 스스로 판단만 | 가장 빠르지만 착각을 놓침 |

- 추천은 **A**. 원칙을 "판단 1번 + 확인 1번"으로 고쳐 적는다.
- 빠르게 훑고 싶은 날을 위해 ⚡ 빠른 훑기 프리셋(나중)은 C로 동작하게 한다.

## 8. 만드는 순서 (11/14까지)

1. 기록 저장·불러오기 + 상자 규칙 (화면 없이 먼저, 시험 코드로 확인)
2. 카드의 체크 흐름 ①~③ (용어 → 뜻 고르기)
3. 목록 맨 위 "오늘의 학습" + 진행 링
4. 대시보드: 상태별 개수, 🚨 착각 목록, 🏅 장기 기억
5. 오늘의 마무리
6. 🗣️ 말하기 모드의 맞음 / 일부 / 아직을 같은 기록에 연결

# 운영 자동화 — 주간 자동 작업 지침서

- 작성일: 2026-11-10
- 결정 근거: `docs/adr/0004-운영-자동화는-점검과-제안까지.md`
- 예약 작업 이름: `field-words-weekly` (Claude 앱의 예약 작업, 이 PC에서 실행)

## 한 줄 요약

**매주 Claude가 자동으로 점검하고(버그·보안·내용), 고칠 방법과 새 용어 후보를 준비해 둡니다. 공개 데이터와 코드는 사람이 승인한 뒤에만 바뀝니다.**

```
[매주 자동]                                    [사람]
 ① 종합 점검 (check_all.py)                      
 ② 오류가 있으면 → 원인 분석 + 수정 제안서        →  제안서 읽고 "고쳐 줘" / "보류"
 ③ 새 용어 후보 20개 (candidates/)               →  앱에서 검토 → 승인 → promote.py
 ④ 내용 보강 제안 (모범 답변·함정·오래된 용어)    →  고를 것만 반영
 ⑤ 주간 보고서 + 알림
```

## 1. 자동으로 하는 일

| 순서 | 일 | 결과물 (Git에 올리지 않음) |
|---|---|---|
| ① | `python pipeline/check_all.py` 실행 | `pipeline/reports/점검_날짜.md` |
| ② | 오류가 있으면 원인을 찾고 고치는 방법을 **글로** 제안 | `pipeline/reports/수정제안_날짜.md` |
| ③ | 승인 대기 후보가 없으면, 용어가 적은 단계부터 새 용어 20개 작성 → `promote.py --dry-run`으로 검사 | `pipeline/candidates/날짜.py` |
| ④ | 모범 답변·현업 함정이 빠졌거나 90일 넘은 용어 중 5개의 보강안 | `pipeline/reports/보강제안_날짜.md` |
| ⑤ | 위 내용을 묶은 주간 보고서 | `pipeline/reports/주간보고_날짜.md` |

## 2. 자동으로 하지 않는 일 (사람 승인 필요)

- `site/` 안의 파일(공개 데이터, 화면 코드) 고치기
- 커밋, 푸시, 배포
- 파일 지우기
- 외부에 메일·메시지 보내기
- 라이브러리 버전 올리기

## 3. 사람이 하는 일 (주 1회, 약 30분)

1. 알림을 받으면 Claude에게 **"주간 보고 보여 줘"**라고 말합니다.
2. **수정 제안**: 읽고 "고쳐 줘"라고 하면 Claude가 고치고, 브라우저로 확인한 뒤 커밋합니다.
3. **새 용어 후보**: 검사만 통과한 상태로 둡니다. 앱에서 보려면 Claude에게 "후보 미리 넣어 줘"라고 하면 임시로 넣고 보여 줍니다. 승인하면:
   ```bash
   python pipeline/promote.py pipeline/candidates/날짜.py
   ```
4. **내용 보강**: 마음에 드는 것만 골라 반영을 요청합니다.

## 4. 점검 항목 (check_all.py)

| 구분 | 무엇을 | 오류일 때 |
|---|---|---|
| 데이터 | 스키마·참조 검사 | 배포하면 안 됨 |
| 규칙 시험 | 학습 기록 규칙 단위 테스트 | 복습 날짜 계산이 틀릴 수 있음 |
| 비밀 값 | API 키·토큰·비밀 키 모양 | 키를 바로 폐기하고 새로 발급 |
| 개인정보 | 공개 파일의 전화번호·주민번호·모르는 이메일 | 지우거나 가림 |
| 금지 파일 | `.env`, `research/`가 Git에 있는지 | Git 기록에서도 지워야 함 |
| 캐시 버전 | js·css를 고치고 `?v=`를 안 올렸는지 | 사용자가 옛 화면을 봄 |
| 외부 파일 | 외부 서버 스크립트를 불러오는지 | 공급망 위험 확인 |
| 의존성 | 검사 도구 라이브러리 새 버전 | 변경 내역 확인 후 올림 |
| 내용 보강 | 단계별 용어 수, 빠진 칸, 오래된 용어 | (정보) 다음 작업 후보 |

## 5. 아직 자동이 아닌 것과 나중 계획

- **수강생 의견**: 지금은 메일(Gmail)로 와서 Claude가 읽을 수 없습니다. 구글 폼으로 바꾸고 구글 연결을 허락하면 ③과 함께 자동으로 분류·제안합니다.
- **화면 자동 시험**: 지금은 사람이 요청할 때 Claude가 브라우저로 시험합니다. GitHub에 올린 뒤에는 GitHub Actions에서 점검을 자동으로 돌립니다.
- **보안 취약점 알림**: GitHub에 올리면 Dependabot(의존성 보안 알림)을 켭니다.
- 예약 작업은 **Claude 앱이 켜져 있을 때** 실행됩니다. 꺼져 있었으면 다음에 앱을 열 때 실행됩니다.

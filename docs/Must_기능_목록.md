## Should — 시간이 되면 (중요한 순서)

1. ⭐ **💼 면접 연습 모드 (퀴즈 사다리 4칸)** — 11/14에 여유가 있으면 같이. `interview_q` 무작위 출제 → 30초 타이머 → 소리 내어 답하기 → `interview_a` 모범 답변 보기·듣기 → 맞음 / 일부 / 아직. 성공 지표("10개 중 8개를 30초 안에 설명")를 그대로 연습한다. 별도 버전이 아니라 앱 안의 모드다. LLM 채점은 ADR-0001 조건에 따라 나중에
2. ⭐ **퀴즈 사다리 3칸: 예문 빈칸 채우기** — 예문에서 용어 자리를 비우고 고르거나 입력한다. 데이터 추가 없이 `examples`로 자동 생성
3. **학습 효율 묶음**: 쉼표 카드에 미니 마무리(방금 본 2장 다시) / 오늘 용어 하나 "내 말로 한 문장" / 🌙 잠들기 전 오늘 카드 듣기 / ☀️ 다음 날 첫 문제는 어제 틀린 카드 / 연속 3번 틀리면 한 칸 쉽게 / "오늘 바로잡은 것 n개" / "실전에서 들었어요"·"설명해 줬어요" 버튼
4. **용어 그림**: 혼동 쌍과 핵심 용어부터. v0.1에 혼동 쌍 그림 1~2개 시범 (ADR-0002)
5. **추가 프리셋**: 🧠 거꾸로 퀴즈(뜻 → 3초 쉼 → 용어, 가장 먼저) / ⚡ 빠른 훑기 / 💼 면접 직전(면접 예문만) / 🔁 따라 말하기 / 🌙 잠들기 전(슬립 타이머) / "내 설정"
6. **Media Session API**: 잠금 화면·이어폰 버튼으로 재생·멈춤·다음 카드. 읽기 속도(0.75~1.5배), 발음 다시 듣기
7. **오프라인 동작(서비스 워커)**: 지하철처럼 신호가 약한 곳의 🚶 이동 중 프리셋을 위해. PWA와 함께
8. **복습 기록 내보내기·가져오기**: 휴대폰 교체, 브라우저 데이터 삭제에 대비. 저장 이름 규칙은 `docs/data-model.md`
9. **말하기 모드(STT)**: 기본 꺼짐. ⚠️ v2에서는 학습 모드 안의 "선택" 항목이었다. 일정 때문에 Should로 내렸다. 🗣️ 말하기 연습 프리셋은 STT 없이 "속으로·소리 내어 설명 → 스스로 채점"으로 먼저 만든다
10. 성장 그래프(**장기 기억 수** 기준), 오늘의 학습 계획 자동 생성
11. 연속 학습일 + 쉬는 날 허용, 구체적인 칭찬
12. 대시보드 ⓘ 용어 보기 + 개발자 보기
13. **"새 용어" 표시**: `created_at`으로 계산. 업데이트 안내와 연결
14. 태그별 보기
15. **FSRS**: 기억 예측 알고리즘(오픈소스)으로 복습 날짜 계산. Phase 2. 라이선스는 넣는 날 확인
16. Claude Code 대화 기록 가져오기(개인정보 가리기 포함)
17. 신규 용어 반자동 수집(Phase 2), 수강생 용어 요청
18. 강의별 신규 용어 수 그래프

## Could — 여유가 있으면

- 광고 자리 레이아웃(쉼표 카드·대시보드·검색 결과 칸)만 비워 두기
- 암묵적 신호 분석, 이정표 배지, 알림(PWA)
- PWA 설치, 걷기 감지 자동 전환, CSV 내보내기
- 🎧 이동 중에 들은 카드 수를 내 기록에 따로 표시 (2026-11-11 제안, 사용자 "지금은 그대로"). 복습 상자는 건드리지 않는다: 듣기는 떠올리기가 아니라서 "외웠다"로 치지 않는다

> 준비만 Must: 화면 문구를 `site/i18n/ko.json`에 모아 둔다(국제화, i18n). 외국어 화면과 번역은 Won't(나중 단계).

## Won't — 이번에는 안 함

- 외국어 화면·용어 번역 (준비는 위 i18n 한 줄로 끝. MVP v3 "외국인 사용자 대비" 참고)

- 광고 실제 탑재, 플레이 스토어 출시 (강의 후. 새 ADR 필요)
- 로그인, 기기 간 기록 동기화
- 유튜브 영상 (Phase 3), 애플 앱 스토어
- 보상형 광고, AI 이미지 생성

## 1. 꼭 알릴 것: 데이터 한계 ⚠️

> 2026-11-10 사용자 요청: "수강생에게 오픈할 때 잊지 않고 코멘트할 수 있도록 도와주세요."

- [ ] 단톡방·공지에 **아래 안내문**을 올렸다
- [ ] 앱 안 "정보" 화면에도 같은 내용이 있다 (Must #7)
- [ ] 피드백 창구 링크가 실제로 열린다

**왜 알려야 하나**
- 현장어는 서버와 로그인이 없다(ADR-0001). 학습 기록은 각자 브라우저에만 있다.
- 그래서 **누가 무엇을 자주 틀리는지 자동으로 모을 수 없다.** 혼동 쌍·등급·예문 개선은 내 기록과 수강생 의견에 기댄다.
- 수강생이 이 사실을 모르면 "알아서 좋아지겠지" 하고 의견을 주지 않는다.

### 안내문 초안 (복사해서 쓰기)

```
[현장어 안내]
현장어는 로그인도 서버도 없는 앱이에요.
그래서 여러분의 학습 기록은 각자 휴대폰·브라우저에만 저장되고, 저에게는 오지 않아요.

그 대신 이런 점을 알아 두세요.
1. 자주 틀리는 용어나 헷갈리는 짝을 제가 자동으로 알 수 없어요.
   → 틀린 설명, 헷갈리는 용어, 추가했으면 하는 용어가 있으면 알려 주세요.
2. 휴대폰과 노트북의 기록은 합쳐지지 않아요.
3. 브라우저 데이터를 지우면 기록도 지워져요.

의견 보내기: (피드백 창구 링크)
여러분의 의견으로 혼동 쌍, 난이도, 예문을 고칩니다. 고친 내용은 업데이트 때 알려 드릴게요.
```

**피드백 창구: 결정됨 (2026-11-10)**
- 앱 안 "의견 보내기" 화면(`#/feedback`, 카드마다 "이 용어에 의견 보내기" 링크)에서 입력 → **Web3Forms**(무료, 월 250건)로 받는 메일에 전달.
- 사용자가 직접 할 일: web3forms.com에서 받을 이메일을 넣고 **Access Key**를 받아 `site/js/app.js`의 `FEEDBACK.accessKey`에 넣는다. (키는 공개돼도 되는 값. 계정 만들기는 사용자가 직접 한다)
- 키를 넣기 전에는 사용자의 메일 앱을 여는 방식(mailto)으로 대신 보낸다.
- [ ] Access Key를 넣고 시험 전송 1건을 받아 봤다

(아래는 처음 검토한 후보)
| 후보 | 장점 | 단점 |
|---|---|---|
| 구글 폼(익명) ⭐ 추천 | 계정 없이 1분. 익명이라 개인정보를 받지 않는다 | 답장을 줄 수 없다 |
| 강의 단톡방 | 가장 쉽다 | 대화에 묻혀 사라진다 |
| GitHub Issues | 기록이 남고 공개적이다 | GitHub 계정이 필요하다 |

- [ ] `python pipeline/validate.py` 통과
